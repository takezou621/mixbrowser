# mixbrowser

X アカウントの自動投稿を効率化する、AI 連携専用ブラウザ(Chromium ベース)のプロジェクトです。
X とは公式 API を使わず、**ブラウザ操作**で連携します。Claude Code / GLM などの AI エージェントと連携し、投稿文の生成から予約・実行までを 1 つのアプリで行います。
